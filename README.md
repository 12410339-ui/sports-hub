# Sports Hub

Sports Hub is a ReactJS website project created for the Web Programming course.

The website provides information about different sports, athlete profiles, sports services, and a contact form for users.

## Features

- Multi-page React application
- React Router navigation
- Responsive layout
- Sports comparison table
- Contact form
- Styled navbar and footer

## Technologies Used

- ReactJS
- JavaScript
- CSS
- React Router DOM

## Setup Instructions

1. Open terminal

2. Run:

```bash
npm install
npm start
```

3. Open localhost in browser
